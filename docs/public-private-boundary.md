# Public / Private Boundary

## Safe to publish
- high-level system diagrams
- public research citations
- synthetic examples
- generic audit-trail patterns
- generic review-state patterns
- public-safe reproducibility examples
- generic model-governance principles
- non-sensitive CI/test examples

## Keep private
- proprietary SDS ontology
- exact scoring formulae or decision rules
- internal annotation instructions
- adjudication datasets
- customer-specific institutional memory
- private enforcement mappings
- design-partner material
- commercial pricing logic
- internal product roadmap
- proprietary benchmark construction logic
- employer/client/government material

**Rule:** If publication would materially help another party reproduce the SDS moat, keep it private.
