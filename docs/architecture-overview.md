# Public Architecture Overview

## Conceptual layers
1. Evidence layer — source identity, provenance, timestamps, traceability.
2. Normalization layer — controlled transformation into structured records.
3. Review layer — human review, exceptions, adjudication, decision traceability.
4. Analytical layer — replaceable public-safe analytical methods.
5. Governance layer — versions, review history, provenance, reproducibility metadata.
6. Output layer — research and review outputs linked to underlying evidence.

## Design principles
- Human judgment remains authoritative.
- AI output is not final adjudication.
- Evidence provenance should be preserved.
- Analytical methods should be replaceable.
- Model and ontology versions should be traceable.
- Validation should explicitly guard against leakage.
- Public artifacts should be reproducible without exposing proprietary logic.
