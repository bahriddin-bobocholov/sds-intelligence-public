# SDS Research Replication — Public-Safe Demonstration

This folder provides a sanitized research-replication demonstration for the Strategic Discretion Score (SDS) research program.

It is designed for faculty, reviewers, and technical readers who want to see reproducible research practice without exposing proprietary SDS scoring logic, ontology details, adjudication data, or confidential materials.

## What this demonstrates
- deterministic data loading
- transparent preprocessing
- public-safe feature construction
- explicit train/test separation
- leakage-awareness
- reproducible metrics
- SHA-256 input hashing
- explicit methodological limitations

## Important limitation
The data in this folder are synthetic. The code does not reproduce the proprietary SDS scoring method, frozen benchmark, production ontology, or original adjudication process.

## Run
```powershell
python reproduce_demo.py
```
