# Validation Notes

The SDS research program distinguishes between source-document holdout, institution-level holdout, prospective blinded review, internal consistency checks, and external predictive validation.

These are not interchangeable.

The public research materials should not be described as proving that SDS predicts future enforcement, fraud, misconduct, or governance failure.

Human review remains essential where language is ambiguous or context-dependent.

A reproducible workflow should preserve:
- input hashes
- split assignments
- model/configuration versions
- output metrics
- evaluation code
- review provenance
